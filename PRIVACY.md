# RE:COPILE privacy notice

Profiles, launch history, statistics, launcher activity badges, settings and
compatibility report drafts are stored on your device. RE:COPILE does not
send them to its developer or Discord automatically. Exporting a profile
summary creates an image that you choose whether and where to share.

Measurements is optional. When requested, hardware detection reads CPU/GPU
models, RAM, operating system and available graphics driver information locally.
It does not collect serial numbers, account credentials or a machine name.
An installed MangoHud or user-selected console PresentMon records local FPS
logs. RE:COPILE uses a private MangoHud configuration with uploads disabled.
Test records retain the game/port version, launch profile, time, manually entered
graphics settings, hardware snapshot and calculated results. CSV imports require
confirmation of the hardware used to record them; importing an external log does
not identify that hardware automatically. Exported reports omit the launch
profile, process ID, local paths and raw CSV. You choose whether to share them. The player launcher has no catalog publication
controls or owner publishing service.


Steam game discovery is optional and **off by default**. Only after you enable
collection matching does RE:COPILE check installed PC editions declared in its
collections, at startup or when you select **Scan Steam**. It reads client
installation locations, `libraryfolders.vdf` and only the `appmanifest_*.acf`
files for those collection App IDs. Windows discovery reads client installation
paths from the registry. Matched titles, app IDs and paths are stored locally;
unrelated Steam games are not imported. You may select an extra library folder.
Disabling the option stops game discovery and disconnects automatic Steam links,
while preserving manually connected programs and recorded profile history.
Scanning does not read passwords, login tokens or purchase history, contact a
Steam web service, download artwork or modify game files. Finding installed
files does not prove account ownership. The ordinary visible-game artwork and
description requests below still apply when you browse matched entries.
Finding installed Proton tools for manually connected Windows programs can also
read Steam library locations; this does not import Steam games.
**Launch in Steam** sends the selected numeric app ID to the installed Steam
client. Steam handles sign-in, licensing, updates and its own network activity.
Steam hours and achievements are not synchronized; the client forwarding
process is not measured as game playtime.

Checking releases, catalogs and project documentation, and downloading programs,
connects to GitHub and its file servers. GitHub receives ordinary connection
data, such as your IP address. You do not need a GitHub account to use the
launcher or download public releases.

Game descriptions and image URLs are requested from English Wikipedia for
visible entries or the game you open. Image files are downloaded from Wikimedia
for visible search results, when you select **Download covers** for the
current page or one game, and for the first game representing each visible
collection tile. Opening a collection does not fetch covers for its full series.
RE:COPILE does not download artwork for the entire
catalog. Wikipedia/Wikimedia receive the requested game title and ordinary
connection data, such as your IP address; RE:COPILE does not send them your
profile, play history or local file paths. Descriptions and covers are cached
locally to avoid repeat downloads.

Optional GitHub sign-in takes place on GitHub's website in your external
browser. RE:COPILE has no GitHub password form, does not read your browser
session and does not store account tokens. A report opens as an issue draft;
you publish it using GitHub's submit button. Public issues may be visible to
others. Review their contents before submitting. A compatibility report includes
the selected game, port version, operating system, hardware/GPU model and your
description. It does not automatically include hardware serial numbers, your
system username, local file paths or passwords.

GitHub Sponsors support is optional and opens an external website. Linux and
Windows contain no advertising SDKs or ad scripts. Android support is deferred.
For a future Android build configured with AdMob, ads are optional and disabled
by default. Enabling the preference does not replace the consent required by
Google: its UMP form is presented before an ad request. You can turn ads off
and change ad privacy choices in settings. A build without AdMob publisher IDs
does not make advertising requests.

Downloaded ports and emulators are independent programs. Their README, license,
privacy policy, network activity and save handling are governed by their own
projects. RE:COPILE displays project documentation before downloading. Port
preparation can download that project's compilers and dependencies; your game
images and prepared files remain local to the setup workflow. Consult the
selected project's documentation for its behavior. Project license acceptance,
the accepted license hash and optional update consent are stored locally.

Collection purchase links open Steam or the publisher's website in your
external browser. The store receives ordinary connection data and handles
purchases and its own account / license requirements. RE:COPILE does not
collect payment information or infer game ownership from a store link.
